Implementation Guidelines

Key Principles

  • Mobile First: Design for mobile landscape orientation first
  • Performance: Use CSS transforms and opacity for animations
  • Accessibility: Maintain WCAG 2.1 AA contrast ratios
  • Consistency: Use design tokens and avoid magic numbers
  • Progressive Enhancement: Core functionality works without advanced CSS

React Component Structure

// Example HUD Panel Component
const HUDPanel = ({ 
  children, 
  variant = 'default', 
  className = '' 
}) => {
  return (
    <div className={`hud-panel ${variant} ${className}`}>
      {children}
    </div>
  );
};

// Example Resource Item Component  
const ResourceItem = ({ 
  icon, 
  value, 
  label, 
  status = 'normal' 
}) => {
  return (
    <div className={`resource-item ${status}`}>
      <div className="resource-icon">{icon}</div>
      <div>
        <div className="resource-value">{value}</div>
        <div className="resource-label">{label}</div>
      </div>
    </div>
  );
};
